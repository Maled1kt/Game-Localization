# English glossary

**Source terms · en**

The English column is the source for all editions in the 30-entry language preset. Use the ID and context to choose the matching sense in a [locale glossary](README.md). Preserve protected tokens and abbreviations when the project requires them.

## Menus, settings, and saves

| ID | English | Context |
| --- | --- | --- |
| GL001 | New Game | Starts a new game session. If progress will be overwritten, warn the player separately. |
| GL002 | Continue | Continues a playthrough from the main menu. Use a separate label for advancing a wizard. |
| GL003 | Resume | Returns from pause. If the line concerns a file transfer, check whether it resumes the transfer. |
| GL004 | Load Game | Loads a saved game. Distinguish loading a save from downloading data. |
| GL005 | Save Game | Writes a saved game. Use a noun for the saved record. |
| GL006 | Save slot | A place for a save. It may be empty. |
| GL007 | Autosave | A feature or save type. A progress indicator may need a separate in-progress phrase. |
| GL008 | Cloud saves | Saves synced through the cloud. Keep Steam Cloud as the service name. |
| GL009 | Checkpoint | A point reached during play. If a character returns there, check whether it is also a respawn point. |
| GL010 | Settings | A menu section. Use the platform's wording for a physical Options button. |
| GL011 | Apply | Applies selected settings. If changes save automatically, verify what the button actually does. |
| GL012 | Restore Defaults | Use a short reset label when the screen already names what will be reset. |
| GL013 | Difficulty | A setting for the challenge level. Explanatory text may use a longer label. |
| GL014 | Subtitles | Written dialogue or its translation. Distinguish the setting from captions if both are offered. |
| GL015 | Closed captions | Check whether the feature includes meaningful sound cues and speaker identification. Agree on any short label with the team. |
| GL016 | Accessibility | A settings section. The general quality of being accessible may need a different term. |
| GL017 | HUD | Heads-up display. Check which elements the setting controls and distinguish the HUD from the full UI if the project does. |

## Controls and input devices

| ID | English | Context |
| --- | --- | --- |
| GL018 | Press | For a key or button. Where duration matters, distinguish it from Hold. |
| GL019 | Hold | For an action that requires keeping a button pressed. |
| GL020 | Tap | A brief touchscreen contact. For a button, distinguish a short press from a hold when duration matters. |
| GL021 | Swipe | A touch gesture. Keep the specified direction. |
| GL022 | Controller / gamepad | A game input device. Use project terminology for a specific device. |
| GL023 | Analog stick | General game UI. Use the approved platform wording in device-specific labels. |
| GL024 | D-pad | The directional pad on a controller. Use the project's PlayStation wording where specified. |
| GL025 | Trigger | A controller input. For an event or mechanism, choose wording that fits the context. |
| GL026 | Key binding | Assignment of a key to an action. Distinguish the setting label from the action of rebinding. |
| GL027 | Sensitivity | Specify what it controls when several sensitivity settings appear together. |
| GL028 | Dead zone | An input range in which no input registers. Confirm the device and setting. |
| GL029 | Invert Y-axis | For vertical direction. Preserve the axis and input type. |
| GL030 | Vibration | Check whether the project treats it separately from device haptics. |

## Combat and gameplay mechanics

| ID | English | Context |
| --- | --- | --- |
| GL031 | Health / HP | An approved abbreviation can fit a compact counter. |
| GL032 | Damage | For combat and stats. Physical damage to an object may use a different term. |
| GL033 | Damage over time (DoT) | For damage dealt in ticks. If the effect is continuous, check the mechanic. |
| GL034 | Damage per second (DPS) | For the metric. A team role may need different wording. |
| GL035 | Critical hit | A hit with a critical effect. Keep weapon-specific wording consistent with the project. |
| GL036 | Ability | An active or passive property. If Ability and Skill are distinct, record the distinction. |
| GL037 | Skill | A learned or upgradeable skill. Keep it distinct from an active ability when the game does. |
| GL038 | Cooldown | The delay before an ability can be used again. Distinguish it from reloading a weapon. |
| GL039 | Reload | The action of reloading a weapon. |
| GL040 | Respawn | Returning after death. Wording for a creature or object that reappears depends on the mechanic. |
| GL041 | Spawn point | A location where an entity appears. Use a separate term for a return after death when the mechanics differ. |
| GL042 | Friendly fire | Fire directed at allies. If the mechanic covers every source of allied damage, consider a wider term. |
| GL043 | Aim down sights (ADS) | The mode for raising a weapon and aiming through its sights. Distinguish it from other aiming modes if needed. Keep ADS when it is a protected token or approved abbreviation. |

## Items, objectives, and progression

| ID | English | Context |
| --- | --- | --- |
| GL044 | Inventory | A character's item list or storage. |
| GL045 | Equipment | A gear category or set. Distinguish it from the verb used to equip or wear an item. |
| GL046 | Loadout | A saved gear configuration. A short label can work if the UI makes the scope clear. |
| GL047 | Loot | Items the player obtains. The verb for taking loot depends on whether the player collects items or searches a container. |
| GL048 | Drop rate | Use a probability label when the value is a chance per attempt. Use a rate label for occurrences per unit of time or events. |
| GL049 | Crafting | Making items. Check whether the game has a separately named profession system. |
| GL050 | Upgrade | Use the verb for the action and the noun for the result or category. |
| GL051 | Quest | A player task. Distinguish Quest, Mission, and Objective when they have separate roles. |
| GL052 | Mission | Often a stage of a campaign. Keep the project's distinction between missions and quests. |
| GL053 | Objective | A goal or completion condition for a quest or mission. Keep it distinct from a combat target. |
| GL054 | Experience points (XP) | Points used to measure progression. A counter can use an approved abbreviation. |
| GL055 | Level | Can refer to character progression or a stage of the game. Add a definition where needed. |
| GL056 | Achievement | For the general mechanic and Steam. See Trophy below for the PlayStation feature. |

| ID | English | Context |
