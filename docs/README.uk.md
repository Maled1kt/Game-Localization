# Game Localization

![Game Localization by Maled1kt](../assets/game-localization-banner.png)

[English](../README.md) · [Усі мови](../README.md#languages)

Game Localization — навичка для агентів, яка перекладає, редагує й перевіряє тексти відеоігор у ChatGPT, Codex і Claude. Вона підходить для меню, навчання, діалогів, субтитрів, текстів магазинів і проєктної документації для Steam, PlayStation, Xbox та мобільних ігор.

[Встановлення](#встановлення) · [Як користуватися навичкою](#як-користуватися-навичкою) · [Оновлення й видалення](#оновлення-й-видалення) · [Підтримати автора](#підтримати-автора) · [План розвитку](../ROADMAP.md) · [Історія змін](../CHANGELOG.md)

## Можливості

- Застосовує затверджену термінологію проєкту й зберігає нові терміни як пропозиції.
- Зберігає ключі локалізації, заповнювачі на кшталт `{player_name}` і `%s`, теги, значущі розриви рядків та інші захищені елементи.
- Перевіряє задані обмеження довжини та відокремлює переклад від запитань, виправлень джерела й приміток контролю якості.
- Пропонує [набір із 30 мов і варіантів](../game-localization/references/game-localization-rules-v0.1.md#21-select-target-languages) та приймає власні списки.
- Містить [початковий глосарій із 75 термінів для всіх 30 мов і варіантів](../game-localization/references/glossary/README.md) зі спільними визначеннями англійською та пропозиціями перекладу.

Навичка містить інструкції та довідкові файли. Вона працює без ключа API проєкту, конектора чи фонової служби. Можливість редагувати файли залежить від інструментів у чаті. Перед випуском перевірте інтерфейс у збірці гри, а тексти магазину — у попередньому перегляді платформи.

### ChatGPT і Codex

1. У вебверсії ChatGPT відкрийте функцію завантаження плагінів. Власники й адміністратори з відповідним доступом можуть скористатися **Admin console → Plugins → Add → Upload plugin**.
2. Виберіть ZIP плагіна. Після перевірки відкрийте **Game Localization** у **Plugins** і виберіть **Install plugin**, якщо ця дія доступна. Особисте завантаження може з’явитися в **Personal → Created by me**.
3. Відкрийте новий чат у ChatGPT або Codex. Введіть `@` і виберіть **Game Localization** із пропозицій.

Якщо робочий простір підтримує окремі навички, завантажте ZIP через **Plugins → Skills → Create → Upload from your computer**. Дочекайтеся перевірки й дотримуйтеся підказок. Параметри залежать від облікового запису й робочого простору. [Посібник OpenAI з плагінів](https://help.openai.com/en/articles/20001256-plugins-in-chatgpt) · [Посібник OpenAI з навичок](https://help.openai.com/en/articles/20001066-skills-in-chatgpt)

### Claude

1. Увімкніть **Code execution and file creation** у налаштуваннях Claude, якщо цього вимагає обліковий запис або робочий простір.
2. У вебверсії Claude або Claude Desktop відкрийте **Customize → Skills**. У новому інтерфейсі відкрийте **Plugins** на бічній панелі й знайдіть керування в **Your plugins**.
3. Виберіть **+ → Create skill → Upload a skill** і ZIP окремої навички. Увімкніть `game-localization`, коли вона з’явиться.
4. Відкрийте новий чат і попросіть Claude використати **Game Localization**. Якщо навичка є в меню **+** або **/** поля вводу, виберіть її там.

У керованому робочому просторі вмикати або завантажувати навички може адміністратор. [Посібник Claude з навичок](https://support.claude.com/en/articles/12512180-use-skills-in-claude) · [Нова бічна панель Claude](https://support.claude.com/en/articles/17740565-manage-plugins-skills-and-connectors-from-one-plugins-page)

### Встановлення для локальних агентів однією командою

Команди використовують гілку `main` репозиторію [Maled1kt/game-localization](https://github.com/Maled1kt/game-localization). Вони працюватимуть після публікації репозиторію та гілки. Відносні посилання на ZIP працюють і в інших гілках, тегах та форках.

У локальному чаті Codex виберіть вбудований `$skill-installer` і надішліть запит нижче. За потреби дозвольте доступ до мережі й розпочніть новий сеанс. [Посібник Codex з навичок](https://learn.chatgpt.com/docs/build-skills)

~~~text
$skill-installer Install the skill from https://github.com/Maled1kt/game-localization/tree/main/game-localization
~~~

Стороння утиліта Skills CLI встановлює одну папку джерела для локального Codex і Claude Code однією командою. Запустіть її в потрібному проєкті з Node.js 22.20 або новішою версією. Залиште параметри `-a` для потрібних агентів. Додайте `-g`, щоб встановити навичку на рівні користувача. [Довідка Skills CLI](https://github.com/vercel-labs/skills/blob/main/docs/commands.md#skills-add)

~~~bash
npx skills add https://github.com/Maled1kt/game-localization/tree/main/game-localization -a codex -a claude-code
~~~

У локальному термінальному чаті Claude Code введіть команду в оболонку для встановлення лише в Claude. Перед запуском перевірте URL репозиторію. [Введення команд у Claude Code](https://code.claude.com/docs/en/interactive-mode#shell-mode-with--prefix)

~~~text
! npx skills add https://github.com/Maled1kt/game-localization/tree/main/game-localization -a claude-code
~~~

У новому сеансі викличте `$game-localization` у Codex або `/game-localization` у Claude Code. Для ручного встановлення скопіюйте всю папку `game-localization/` до `.claude/skills/` у проєкті або `~/.claude/skills/` користувача. [Посібник Claude Code з навичок](https://code.claude.com/docs/en/skills)

У хмарних ChatGPT і Claude користуйтеся функціями завантаження або встановлення облікового запису. Згадка в чаті викликає встановлену навичку. Щоб поділитися посиланням, опублікуйте навичку в каталозі платформи або надайте доступ до навички чи плагіна в робочому просторі з такою можливістю. [Спільний доступ до плагінів ChatGPT](https://help.openai.com/en/articles/20001256-plugins-in-chatgpt) · [Спільний доступ до навичок Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

## Як користуватися навичкою

1. Додайте вихідний текст або файл і актуальний глосарій проєкту для цільових мов. Якщо глосарія немає, прямо попросіть підготувати чернетку.
2. Вкажіть вихідну й цільові мови, платформу, тип матеріалу й формат результату. За потреби додайте обмеження символів, знімки екрана, відомості про мовців або приклади змінних.
3. Для таблиць назвіть вихідні та цільові стовпці й попросіть нову копію. Для ігрових рядків надайте сталі ID або ключі. Для магазину вкажіть цільове поле та обов’язкове обмеження довжини, якщо є.
4. В окремому звіті зазначено, чи готовий результат до використання, чи це ще чернетка. У звіті окремо показано перевірку файлу, мовну перевірку та перевірку в грі або в попередньому перегляді магазину. Для кожної невирішеної проблеми вказано наступний крок. Затвердьте терміни в глосарії проєкту перед повторним використанням.

Скористайтеся [шаблоном глосарію проєкту](../game-localization/references/project-glossary-template.md), щоб зберігати затверджені терміни окремо від пропозицій. Збережіть оновлений файл і додайте його до наступного чату.

**Приклад запиту для таблиці**

~~~text
Використай Game Localization, щоб перекласти стовпець ENGLISH доданої книги німецькою (de-DE). Запиши переклади у GERMAN у новій копії .xlsx. Використай доданий глосарій і стовпець DESCRIPTION як контекст. Збережи ключі, вихідні стовпці, заповнювачі й теги. Подай питання про терміни та результати перевірок окремо з ID рядків.
~~~

Для підтримуваних файлів `.xlsx` укажіть аркуш, рядок заголовків, стовпець зі сталими ID, вихідний стовпець і наявний стовпець перекладу. За наявності Python 3.9 або новішої версії навичка записує переклади за ID в нову копію та перевіряє, чи збережено решту книги. Якщо перевірити книгу неможливо, навичка може запропонувати CSV з ID рядків. [Інструкція для Excel](../game-localization/references/xlsx-qa.md)

**Приклад запиту для сторінки магазину**

~~~text
Використай Game Localization, щоб локалізувати цей короткий опис Steam з англійської бразильською португальською (pt-BR). За потреби підготуй чернетку глосарія. Збережи назву гри та дотримуйся заданого ліміту символів. Поверни текст магазину й окремий звіт.
~~~

### Перевірка перекладів у CSV

Якщо рядки CSV мають сталі ідентифікатори, укажіть заголовки стовпців з ID, вихідним текстом і перекладом. Якщо доступний Python 3.9 або новіший, навичка порівнює вихідний файл із перекладом і повідомляє про пропущені або повторювані ID, порожні переклади, зміни в підтримуваних заповнювачах або тегах і перевищення обмежень довжини. [Інструкція з перевірки CSV](../game-localization/references/csv-qa.md)

Спробуйте [навчальний приклад із 12 рядків](../game-localization/examples/first-run/README.md) із чернеткою перекладу, затвердженим глосарієм і зразком звіту.

## Вихідні файли й пакування

- [`game-localization/SKILL.md`](../game-localization/SKILL.md) визначає умови запуску й оброблення пакета рядків.
- [`game-localization/references/`](../game-localization/references/) містить правила та мовні версії початкового глосарія.
- [`packaging/chatgpt/`](../packaging/chatgpt/) містить маніфест і піктограму плагіна.
- [`packages/`](../packages/) містить готові до завантаження архіви.

Щоб зібрати обидва ZIP з тих самих джерел, виконайте `python scripts/package.py` в корені репозиторію з Python 3.9 або новішою версією. Номер версії береться з маніфесту плагіна ChatGPT. Перед поширенням завантажте кожен ZIP у відповідний продукт і перевірте невеликий пакет із глосарієм і захищеним заповнювачем.
